# G-AI-A Prototype 🚀🤖

## Hi there, User! 👋 Thank you for using my creation. This is a gardening assistant LLM.

# Available commands:
### load/use [model]  - Load a specific model (plant/random/farmbot).    
### unload/remove [model] - Unload a specific model (plant/random/farmbot).
### list models - Show loaded and available model.
### memory/status - Check memory usage.
### (connect / connect to) farm - Connects to farmbot control unit
### (disconnect from/ shutdown) farm - Terminates farmbot control unit connection

# Available Models
### Plant Care Database - plant
### Farmbot command Database - farmbot
### Random Training Database - random
